Firmware

Latest: – · On pyramid: connect to check

Firmware updates need Chrome or Edge on a computer. Firmware updates need this page to be opened over https.

Switch the pyramid on, click Update firmware and pick it from the list. Your saved pattern is kept. If the pyramid stays dark afterwards, switch it off and on again.

Each set loops on its own. A keyframe fades in from the previous keyframe's colour over Fade, then stays for Hold. One keyframe = solid colour; no keyframes = off.
